# Portfolio Website

A HTML and CSS website for displaying and keeping a record of my projects and skills and an alternative online CV. It displays as of now three of my projects and also gives a summary of the skills acquired. The website also contains a contact form and My one click downloadable CV.

# Deutsch

Eine HTML- und CSS-Website zur Präsentation und Dokumentation meiner Projekte und Fähigkeiten sowie ein alternativer Online-Lebenslauf. Aktuell werden drei meiner Projekte vorgestellt und eine Zusammenfassung der erworbenen Kenntnisse gegeben. Die Website enthält außerdem ein Kontaktformular und die Möglichkeit, meinen Lebenslauf mit einem Klick herunterzuladen.
